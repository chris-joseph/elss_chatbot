# How can I start a SIP on Groww?

Loading... To start a SIP on Groww: From the Home screen, go to the 'Mutual Funds' section.

* Click on 'Explore' at the top.

* Search for or select the mutual fund you want to invest in.

* Click on 'Start SIP.'

* Enter the amount.

* Select the date (when the amount will be deducted monthly).

* Pay via UPI or Netbanking.

* Don’t forget to add AutoPay via OTP or form for future installments. Note:

* The SIP can only be set up on a monthly basis. Weekly, bi-monthly, quarterly, and half-yearly SIP options are not available.

* When you set up a new SIP, the first month is often skipped because there needs to be a minimum of 30 days between the first and second installments. Click the button below to go directly to the ' Explore ' tab in the Mutual Funds section.
